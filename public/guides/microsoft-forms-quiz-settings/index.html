Microsoft Forms Quiz Settings for Tests: A Teacher’s Checklist

Microsoft Forms is free with a Microsoft account and included in most school Microsoft 365 plans. A few settings make a big difference when you use it for a real test.

1. Start with a Quiz, not a Form

Choose New Quiz rather than New Form. A quiz lets you mark the correct answer for each question, give points, and add feedback that students see after their results are released. You can still add any question type: choice, text, rating, date and more.

2. Set points and correct answers

  • For each choice question, tick the correct option and set the points.
  • For text answers, you can add accepted answers for short responses, or grade longer answers yourself in Responses → Review answers.
  • Add short feedback to tricky questions. It’s a quick way to teach from mistakes once results are shown.

3. Shuffle the options

On each choice question, open the … menu on the question and choose Shuffle options. Each student then sees the choices in a different order, so “the answer to number 4 is B” means nothing.

4. Open the settings

Open the … menu at the top right of the form and choose Settings. These are the options to check:

SettingWhat it doesSuggestion for tests
Who can fill out this formOnly people in my organization requires a school sign-in and can record names. Anyone can respond needs no sign-in.Use Anyone can respond if students take it inside QuizPolice, and ask for the name in QuizPolice or as the first question.
Start date and End dateThe form only accepts responses between these times.Set both for a scheduled test, as a backup to your own timing.
Shuffle questionsShows the questions in a different order for each student.Turn on, unless questions build on each other. You can keep some fixed if you use sections.
Show results automaticallyStudents see their score and the correct answers right after submitting.Turn off for tests, so early finishers can’t share answers. Release results after everyone has finished.
Accept responsesTurns the form on or off.Turn off as soon as the test ends.

Some options, like recording names or limiting to one response per person, only appear when sign-in is required. Microsoft adds and moves settings from time to time, so if you don’t see one, check the latest Microsoft Forms help for your account type.

5. Using it inside QuizPolice

When a form needs a school sign-in, that sign-in often fails inside another site, because browsers block the cookies it needs. So for QuizPolice, set Who can fill out this form to Anyone can respond. Then:

  1. Copy the link from Collect responses.
  2. Create a quiz on the QuizPolice dashboard, paste the link and press Check this link.
  3. Choose the exit limit and timing: anytime, a scheduled exam, or an open period.
  4. Students join with the code, type their name and section, and answer inside QuizPolice. You see who leaves the quiz, live.

Answers still go straight to your Microsoft form, so grading in Responses works exactly as before.

6. Test it before the class does

  • Open the form in a private browser window, not signed in, and answer it once as a student would.
  • Check that your test response arrives in Responses, then delete it.
  • Read every question on a phone screen. Long matching tables and small images are hard to read on phones; split them into shorter questions.

7. After the test

  • Turn off Accept responses.
  • Review open answers in Review answers, then share results with students the way your class usually does.
  • Download your QuizPolice results (names, sections, exits and time away) for your records, and talk privately with any student whose record raises questions.
