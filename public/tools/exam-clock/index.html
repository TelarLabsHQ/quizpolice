Exam clock

It opens full screen. Press F for full screen, Space to pause.

An exam clock is still running.

00:00

    How to use it

    1. Type the exam title and either its length or the time it ends.
    2. Add the rules students should see the whole time.
    3. Tap Start and put it on the projector or TV. Students see the time left, the end time and the rules in big letters.
    4. At 10 and 5 minutes left, the screen changes color with a short beep. At zero it says the time is up.

    Good to know

    • Keyboard: Space pauses, F goes full screen, + and − add or remove 5 minutes.
    • If the page is closed or refreshed, the clock picks up where it was, because the end time is saved in this browser.
    • The screen is kept awake while the clock runs, on browsers that allow it.
    • Giving the exam online too? Set it up in QuizPolice with a time limit, so each student’s quiz closes on time and you see who leaves it.
