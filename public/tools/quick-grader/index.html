Quick grader

Using shared quick grader settings.

Grades below the pass mark are in red.

How to use the quick grader

  1. Type the number of items on the test.
  2. Choose whether you count the number wrong or right. Most teachers count mistakes, since there are fewer.
  3. Pick how to show the grade: a letter, a percentage, or a converted grade from a transmutation table.
  4. Print the chart and keep it beside you while checking. Count the mistakes, find the number, write the grade.

Example

On a 40-item test, each item is worth 2.5%. A student with 3 wrong got 37 right: 37 ÷ 40 = 92.5%, an A− on the A to F scale. With 12 wrong, 28 ÷ 40 = 70%, a C−.

Tips

  • Half points: for questions with partial credit, choose “Half points too” and the chart adds 0.5, 1.5, 2.5 and so on.
  • Your school’s own conversion: make your table in the transmutation table maker, then choose “My rule” here.
  • Same chart for the whole department: tap Copy link and share it.
  • To combine test scores with homework, projects and exams, use the grade calculator.

Questions

Is this like an EZ grader?

Yes. It does the same job as a paper slide grader or an “EZ grader” chart, but you can set the number of items, the grade scale and the pass mark, and print it.

Is anything saved or uploaded?

Your settings stay in this browser so the chart is ready next time. Nothing is sent to a server.
