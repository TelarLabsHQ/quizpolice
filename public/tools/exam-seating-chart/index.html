Exam seating chart

FRONT · BOARD · TEACHER’S DESK

Seats by name

    How to use it

    1. Type the number of rows (front to back) and seats in each row, then paste your class list.
    2. Choose the number of test sets. The chart gives neighbors different sets, so the student beside, in front of or behind has a different paper whenever the room allows it.
    3. Choose spacing if you have room: a staggered gap between students, or empty rows.
    4. Fix it by tapping: swap two students, or block a broken or reserved seat. Then print it, or show it on the projector as students come in.

    Tips for a fair exam room

    • Post the seats by name list at the door so students find their seat quickly.
    • Shuffle a new chart for each exam, so students don’t sit by the same friends every time.
    • Pair it with the test set shuffler to make Sets A, B, C, and the exam clock on the projector.

    Questions

    How are sets given out?

    Seat by seat, the chart picks the set that differs most from the students nearby, and keeps the number of each set even. With 2 sets, students side by side and front to back get different sets; with 4 sets, every neighbor, even diagonally, does.

    Is my class list saved?

    Only in this browser on this device. Nothing is uploaded.
